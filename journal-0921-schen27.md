What does "defensive programming" mean, in your own words?
Defensive programming is writing the code that can allow unexpected actions or input and avoid crashing.  

Which Python tool is most important for security — try/except, type conversion, or input validation? 
I think input validation is most important for security because it can stop wrong-formatted input before it go through the program and make it crash. There will still be things that you haven't thought of that your try/except couldn't catch. Type conversion only can convert the format, there's no guanrantee that it will work after the input is converted.
